About the Flask Blogging Platform

This project is developed as part of the DIY Internship Program. The objective is to build a full-featured blogging web application that empowers users to register, write and publish rich-text articles, explore topics by categories, and interact via comments.

Technologies & Tools

Python 3.14 Flask 3.x SQLAlchemy Flask-Migrate Flask-Login Flask-WTF Jinja2 SQLite

Internship Roadmap

  • Week 1 Flask setup, application factory, Blueprints, SQLAlchemy models & migrations.
  • Week 2 User registration, login/logout sessions, authentication forms with CSRF validation.
  • Week 3 Blog post CRUD operations, rich text editor, category/tag tagging.
  • Week 4 Interactive commenting, search/filter capabilities, final polish & deployment.
